# Juliet & Andrew — Digital Wedding Invitation

**Saturday, December 19, 2026 • Victoria Island, Lagos** — A fine-art digital wedding invitation built from scratch with HTML, CSS, and JavaScript.

## About the Project
An interactive wedding invitation website designed to share ceremony and reception details, a wedding day timeline, an engagement photo gallery, a live ticking countdown clock, and a digital RSVP guest pass generator.

## Design & Aesthetic
* **Fine-Art Conservatory Palette:** Blends Romantic Dusty Rose, Pearl White, and Warm Ivory with Botanical Sage Green and Antique Gold accents.
* **Typography:** Pairs italic *Cormorant Garamond* editorial headings with clean *Plus Jakarta Sans* event details.

## Features
* **Real-Time Wedding Countdown:** Live ticking JavaScript countdown timer calculating exact days, hours, minutes, and seconds until the ceremony.
* **Celebration Details & Order of Events:** Structured ceremony, reception, attire, and wedding-day milestone timeline cards.
* **Digital RSVP Guest Pass Modal:** Submitting the RSVP form generates a personalized boarding-style digital invitation pass complete with a unique pass number, party size, and dietary/song notes.

## Built With
* **HTML5** — Semantic invitation layout
* **CSS3** — Custom variables, CSS Grid, Flexbox, and romantic hover transitions
* **Vanilla JavaScript** — Real-time `setInterval` countdown clock and dynamic RSVP guest pass generator
